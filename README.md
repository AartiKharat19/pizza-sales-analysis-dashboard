# pizza-sales-analysis-dashboard
Pizza Sales Analysis using Power BI to analyze revenue, orders, pizza sales, and customer preferences.
# Project Overview

The Pizza Sales Analysis project focuses on analyzing pizza sales data to understand sales performance, customer preferences, and business trends using Microsoft Power BI.
The dashboard provides insights into total revenue, total orders, pizzas sold, average order value, popular pizza categories, pizza sizes, and sales trends.
# 🎯 Project Objectives

- Analyze overall pizza sales performance.
- Identify the most popular pizza categories and sizes.
- Find the best-selling and worst-selling pizzas.
- Understand daily and monthly sales trends.
- Identify peak sales periods.
- Support data-driven business decisions.

# 🛠️ Tools & Technologies

Microsoft Power BI – Dashboard creation and visualization

Power Query – Data cleaning and transformation

DAX – Calculated measures and KPIs

CSV / Excel – Data source

# 📊 Key Performance Indicators (KPIs)

- Total Revenue
- Total Orders
- Total Pizzas Sold
- Average Order Value
- Average Pizzas Per Order
# 📈 Dashboard Analysis

The dashboard analyzes the following areas:

1. Sales Overview:Provides an overview of revenue, orders, pizzas sold, and average order value.

2. Category Analysis:Analyzes sales performance across different pizza categories.

3. Size Analysis:Examines customer preferences for different pizza sizes.

4. Best & Worst Sellers:Identifies top-performing and low-performing pizzas based on revenue, quantity sold, and total orders.

5. Daily & Monthly Trends:Highlights sales patterns by day of the week and month to identify peak business periods.
